01observed · no decision recorded

The problem

Memory is not enough.

A stored answer can be outdated. A successful procedure can fail when the task changes. Keeping more history does not tell an agent what to trust or do next.

The challenge is to connect retained experience to decisions, and to notice when the past has become a liability.

02accepted · decision recorded

Public technical work

Agent Memory Contracts

An agent’s interpretation should not silently become a fact. Agent Memory Contracts is a public Python library for making that boundary explicit.

Source evidence stays linked to a candidate claim. Accepting the claim requires a recorded decision, and the validator rejects a trusted record without the required authorization. The worked reducer example shows acceptance, rejection and an invalid promotion.
